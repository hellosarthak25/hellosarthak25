<a href="https://github.com/hellosarthak25/content-moderation-system">
  <img src="https://img.shields.io/badge/VIEW_PROJECT-GitHub-6366F1?style=for-the-badge&logo=github" />

<a href="https://content-moderation-system-nf9s.onrender.com/">

An AI-powered application that detects and classifies toxic online comments using Natural Language Processing and a fine-tuned DistilBERT model.

**Key Highlights:**

- Multi-label toxicity classification.
- Detection across six toxicity categories.
- Automated moderation decisions.
- FastAPI backend and interactive dashboard.
- SQLite-based moderation audit logging.

**Tech Stack:** Python · PyTorch · DistilBERT · NLP · FastAPI · SQLite
